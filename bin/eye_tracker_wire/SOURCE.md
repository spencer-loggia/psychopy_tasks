# Eye tracker UART client

Adapted from `eye_tracker/src/macaque_tracker/{protocol,controller,uart}.py`
at commit `5c0e12e2e373f0ac0ac9bb4c723e7a42d93d7c39` (MIT; see LICENSE).
The wire format is specified in that project's `docs/protocol.md`.

Only controller-side encoding/decoding, request acknowledgement/retry logic,
and exclusive raw UART access are retained. Camera-dependent models, status
encoding, the Unix socket backend, sample iterator and CLI are omitted.
The decoded eye record is a local dataclass to avoid a camera/NumPy dependency.
Runtime configuration and eye-0 validity/filtering live in `bin/eye_tracking.py`.
Update these routines together when the tracker protocol changes.

Experiment commands, subject payload validation, and EXPERIMENT_ACTIVE /
CALIBRATING status flags were synchronized on 2026-10-14 with the companion
checkout's staged Pi Tracker changes on HEAD
`de4b8ca753f25d4da21cd98253d01ff2a63c76ae`. These changes were not yet committed
upstream. `tests/fixtures/eye_uart_v1.json` includes experiment packets generated
by that checkout's codec, as well as the original telemetry fixtures.

SHUTDOWN (command 8), SHUTTING_DOWN (status bit 7), and the controller shutdown
helper were synchronized on 2026-10-15 from companion commit
`44ac5f50ee27c6a2a6896cf0efe472b20130cf9c`. The fixture file also includes its
codec-generated shutdown command and acknowledgement.

Experiment/block numbers at command header offset 12, positive uint32 validation,
and numbered controller start helpers were synchronized on 2026-10-19 from the
companion working tree on HEAD `c966ff374eb43825dc060b90cf1339db4e32070f`.
The numbered-start changes were not yet committed upstream. The fixture file
records the source codec's SHA-256 and three packets generated by that checkout
for numbered experiment, tracking, and recording starts. Protocol version,
transaction size, subject payload, telemetry, and identical-packet retry behavior
are unchanged.

Local latency changes on 2026-10-21 keep wire packets and sequence matching unchanged:
state retries now use the short response timeout before retransmitting, with the full
action timeout reserved for the final attempt. INFO logs distinguish tty write time
from response wait time. These controller-side changes have not been synchronized
with the companion repository.
